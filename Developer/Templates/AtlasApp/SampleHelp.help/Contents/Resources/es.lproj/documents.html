Trabajar con documentos

Ejemplo guarda tus cambios mientras trabajas: no hace falta guardar antes de cerrar una ventana o salir.

Versiones

  1. Elige Archivo → Nuevo para empezar un documento.
  2. Elige Archivo → Guardar… para darle un nombre y un lugar.
  3. Elige Archivo → Volver a → Explorar todas las versiones… para volver a una versión anterior.
