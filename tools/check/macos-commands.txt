# The command-line tools a macOS install has in /bin, /sbin, /usr/bin and
# /usr/sbin that people use, from macOS's public manual pages: the
# reference commands-report.py measures Minkar's sysroot against. Not every
# file there: Xcode's developer tools, Perl and Python scripts and private
# helpers are left out.
#
# One per line: DIRECTORY NAME KIND
#   bsd      a BSD or other portable tool (FreeBSD main first)
#   apple    macOS's own: Minkar writes it (often needs a later phase)
#   fs       a file system's tool: needs that file system in the kernel
#   licence  its licence needs the project's approval first
#   builtin  a shell builtin macOS also has as a file (/usr/bin/cd...)
#   darwin   Darwin's own component, kept from Apple's open source
