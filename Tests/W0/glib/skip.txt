# A file's changes-done-hint comes from kqueue's NOTE_CLOSE_WRITE, which
# Darwin's kqueue does not have (the reference platform's neither); GLib

# six tests of the program pass.

# variable named "foo=bar"; GLib marks it as allowed to fail on Darwin.
environment:/environ/getenv expects getenv() to keep '=' in a name, as the reference platform's Libc does not
