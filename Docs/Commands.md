# Command-line tools

How many of the commands a macOS user types Minkar has, and how many it still lacks. This page is generated by `tools/check/commands-report.py` from a built sysroot; the reference list is `tools/check/macos-commands.txt` (354 commands of macOS's /bin, /sbin, /usr/bin and /usr/sbin, without Xcode's developer tools or Perl and Python scripts).

Each command comes from FreeBSD main where FreeBSD has it, and behaves as on macOS where the two differ; each has its manual page and its tests.

## Against macOS

245 of the 354 reference commands are in the image; 109 are missing.

| Kind | In the image | Missing | What it takes |
|---|---:|---:|---|
| BSD and other portable tools | 230 | 42 | Ported from FreeBSD main (or their own upstream), as the ones before. |
| macOS's own tools | 5 | 41 | Written for Minkar; many need the graphical system or frameworks of later phases. |
| Darwin's own components | 9 | 5 | Kept from Apple's open source (launchd, configd, syslogd...). |
| File system tools | 0 | 10 | Need the file system (APFS, exFAT, FAT, NFS, SMB) in the kernel first. |
| Licence to approve | 1 | 6 | Their licence (GPL, Vim, CDDL...) needs the project's approval first. |
| Shell builtins as files | 0 | 5 | macOS has /usr/bin/cd and the like: small scripts that run the builtin. |
