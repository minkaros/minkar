# Command-line tools

How many of the commands a user of the reference system types Minkar has, and how many it still lacks. This page is generated by `tools/check/commands-report.py` from a built sysroot; the reference list is `tools/check/reference-commands.txt` (354 commands of its /bin, /sbin, /usr/bin and /usr/sbin, without the developer tools or Perl and Python scripts).

Each command comes from FreeBSD main where FreeBSD has it, and behaves as on the reference system where the two differ; each has its manual page and its tests.

## Against the reference system

337 of the 354 reference commands are in the image; 17 are missing.

| Kind | In the image | Missing | What it takes |
|---|---:|---:|---|
| BSD and other portable tools | 273 | 0 | Ported from FreeBSD main (or their own upstream), as the ones before. |
| The reference system's own tools | 33 | 13 | Written for Minkar; many need the graphical system or frameworks of later phases. |
| Darwin's own components | 15 | 0 | Kept from the original open source (launchd, configd, syslogd...). |
| File system tools | 6 | 4 | Need the file system (APFS, exFAT, FAT, NFS, SMB) in the kernel first. |
| Licence to approve | 5 | 0 | Their licence (GPL, Vim, CDDL...) needs the project's approval first. |
| Shell builtins as files | 5 | 0 | The reference system has /usr/bin/cd and the like: small scripts that run the builtin. |
