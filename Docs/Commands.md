# Command-line tools

How many of the commands a macOS user types Minkar has, and how many it still lacks. This page is generated by `tools/check/commands-report.py` from a built sysroot; the reference list is `tools/check/macos-commands.txt` (354 commands of macOS's /bin, /sbin, /usr/bin and /usr/sbin, without Xcode's developer tools or Perl and Python scripts).

Each command comes from FreeBSD main where FreeBSD has it, and behaves as on macOS where the two differ; each has its manual page and its tests.

## Against macOS

334 of the 354 reference commands are in the image; 20 are missing.

| Kind | In the image | Missing | What it takes |
|---|---:|---:|---|
| BSD and other portable tools | 273 | 0 | Ported from FreeBSD main (or their own upstream), as the ones before. |
| macOS's own tools | 31 | 15 | Written for Minkar; many need the graphical system or frameworks of later phases. |
| Darwin's own components | 15 | 0 | Kept from Apple's open source (launchd, configd, syslogd...). |
| File system tools | 5 | 5 | Need the file system (APFS, exFAT, FAT, NFS, SMB) in the kernel first. |
| Licence to approve | 5 | 0 | Their licence (GPL, Vim, CDDL...) needs the project's approval first. |
| Shell builtins as files | 5 | 0 | macOS has /usr/bin/cd and the like: small scripts that run the builtin. |
