# BSD userland

The commands of Minkar's base system: the policy they follow, where each group comes
from, and how many of the reference system's commands Minkar has. For anyone porting or
fixing a command. Last reviewed: 2026-11-21. Phase 2 of [ROADMAP.md](ROADMAP.md).

## Policy

- The generic Unix commands come from FreeBSD `main` (decided 2026-10-26). Where the
  reference system's command behaves differently (options, output), Minkar's own code
  under `__APPLE__` follows the reference system's manual page, each difference with a
  test.
- Darwin's own components (launchd, configd, notifyd, syslogd, DiskArbitration, the HFS
  and NFS tools, mDNSResponder, dtrace) stay as published, under the APSL.
- Only the commands the reference system has are ported, not every BSD command.
- Licences other than BSD and MIT need the project's approval first.
- Every command has its manual page and its tests.

## Where each group comes from

- **FreeBSD `main`:** the generic commands (file, text, process, user and network tools),
  `man` with `mandoc`, `cron`, `at`, `newsyslog`, `mail`, `telnet`, `ftp` (tnftp), `talk`,
  `mtree`, `fdisk`, `fstyp`, `newfs_msdos`, `fsck_msdos`, `localedef`, `flex`, and the
  password tools sharing `BSD/lib/libpw`. Built with bmake's own rules.
- **NetBSD and OpenBSD:** `shlock` and `rlogin` (NetBSD); `pfctl` from OpenBSD 4.3, the
  release whose pf Darwin's kernel carries.
- **Darwin, as published (APSL):** launchd and `launchctl`, configd and `scutil`,
  notifyd and `notifyutil`, syslogd, DiskArbitration and `diskarbitrationd`, `newfs_hfs`,
  `mount_nfs` and `nfsd`, dtrace (with the kernel's CTF), mDNSResponder.
- **Third-party projects, from their own releases:** bash, zsh, ksh 93u+m, tcsh, dash,
  Vim, nano, git, rsync, OpenSSL (Apache-2.0, as `openssl`), BIND's `dig`, `host` and
  `nslookup`, Heimdal's `kinit`, `klist` and `kdestroy`, tcpdump, lsof, htop, btop,
  Info-ZIP's `zip` and `unzip`, OpenSSH, curl, LLVM's `ar`, `ranlib`, `size` and
  `strings`, Ruby, Python and Perl.
- **Written for Minkar, behaving as the reference system's:** `login`, `top`, `xxd`,
  `uuidgen`, `xattr`, `open`, `hdiutil`, `diskutil`, `autodiskmount`, `mount_msdos`,
  exFAT (`mount_exfat`, `fsck_exfat`, `newfs_exfat` and the kernel driver, from the
  published specification), the quota tools, `vifs`, `lsbom`, `pkgutil`, `bless`,
  `disklabel`, `csrutil`, `vsdbutil`, `kextstat`, `kextload`, `kextunload`, `ioreg`,
  `nvram`, `system_profiler`, `systemsetup`, `sysadminctl`, `networksetup`, `pmset` and
  `powerd`, `emond`, `fs_usage`, `leaks`, `sample`, `dynamic_pager`, `arch`, `vm_stat`,
  `wait4path`, `tzlink`, `purge`, `caffeinate`, `dot_clean`, `rpcbind`, and the shell
  builtins as files in `/usr/bin` (one script that runs `sh`'s builtin).

## Shells

`/bin/sh` runs bash as a POSIX shell, as on the reference system: a small launcher and
`/private/var/select/sh` naming the shell; FreeBSD's `sh` stays as `/usr/libexec/bsdsh`.
bash, zsh, ksh, tcsh (also `csh`) and dash are in `/etc/shells`.

## System data

- **Locales:** 56 UTF-8 locales in `/usr/share/locale`, made by
  `tools/locale/mklocales.py` in the formats Darwin's libc reads: character classes, case
  maps and widths from Unicode; time, money, numbers and messages from FreeBSD's CLDR
  definitions; collation by code point.
- **Time zones:** IANA tzdata compiled by tzcode's `zic`, in `/var/db/timezone/zoneinfo`.
- **Manual pages:** the pages the commands' sources carry.
- **iconv:** FreeBSD's Citrus libiconv (`/usr/lib/libiconv.2.dylib`, 23 encoding modules,
  conversion tables in `/usr/share/i18n`), with Minkar's UTF-8-MAC for the decomposed
  names HFS Plus stores.

## Known problems

- `sshd` records a login but not its logout: `last` shows ssh sessions as still logged in.
- The console's terminal has no node in `/dev`, so `ps` shows `??` for getty.
- Out until after Minkar 19.6.0, with no driver under a usable license: APFS
  (`fsck_apfs`, `mount_apfs`, `newfs_apfs`; no open implementation) and SMB
  (`mount_smbfs`; Samba is GPL). Also `fdesctl`. Minkar's file systems are HFS+, FAT and
  exFAT.
- The reference system's tools that need a later phase (`mdfind`, `mdls`,
  `mdutil`, `say`, `osascript`, `opendiff`, `tmutil`) are listed in
  [ROADMAP.md](ROADMAP.md).
