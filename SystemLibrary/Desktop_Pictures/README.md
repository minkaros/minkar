# Minkar desktop pictures

Light: Blue Daylight, Lavender Dawn. Dark: Soft Dusk, Deep Blue Night.

- `Minkar-*.png`: the original designs, 1672 x 941.
- `High Resolution/`: high-quality (LANCZOS) upscales of the originals in
  JPEG: 4K UHD (3840 x 2160), 5K (5120 x 2880), and ultrawide versions
  cropped to 3440 x 1440 and 5120 x 2160.

The login window uses Soft Dusk and the desktop starts with Blue Daylight.
