Logs Help

Logs shows the messages that programs write with os_log, and the computer’s crash reports and log files.

Messages

Logs shows the last hour’s messages, then each new one as it comes. Click Pause to stop the list moving while you read it.

  • The level menu chooses which messages: Default, Info and Debug show more and more of them; Errors and Faults only those.
  • Type a name in Process or Subsystem to see only theirs, and words in the search field to find a message.
  • Select a message to read it whole below the list.

You see your own programs’ messages; an administrator sees all of them.

Crash reports and log files

Crash Reports lists the reports written when a program stops unexpectedly; Log Files the system’s logs in /var/log and /Library/Logs; My Logs yours. Select one to read it; choose File → Show in Files to see it in its folder.
