Terminal Help

Terminal runs your shell, and the programs you start from it, in a window. It understands the VT100 and xterm terminals’ codes: colors, cursor movement, full-screen programs such as vi and top, and UTF-8 text.

Windows and tabs

  • Shell → New Window (⌘N) and New Tab (⌘T) start another shell.
  • Shell → Close Tab (⌘W) ends the tab’s shell. A tab closes by itself when its shell ends (type exit).
  • Resize the window: the shell and its programs get the new size.

Text

  • Drag to select text; double-click selects a word, triple-click a line. Edit → Copy and Paste work as everywhere.
  • Scroll up to read what went off the top; Edit → Clear Scrollback (⌘K) forgets it.
  • View → Bigger and Smaller change the text’s size.
