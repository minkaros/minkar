System Monitor Help

System Monitor shows the processes running on your computer and what they use. It updates every two seconds.

The tabs

  • CPU: the share of a processor each process uses, its CPU time and its threads.
  • Memory: the memory each process uses, and the computer’s.
  • Disk: the data each process has read and written.
  • Network: the data each network interface has received and sent.

Click a column’s title to sort by it; click it again for the other order. Type in the search field to show only the processes whose names have what you type.

Seeing a process’s information

Select it and choose View → Get Info (⌘I), or double-click it: its parent, user, path, start and use.

Quitting a process

Select it and click the × button, or choose View → Quit Process. Quit asks it to end; Force Quit ends it at once, and changes it has not saved are lost.
